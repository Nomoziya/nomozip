功能行为
任务控制行按钮只控制此解压任务；工具栏控制全队列。全局继续保留单任务暂停状态。
备份提醒只有成功导出登记时间；失败或取消不登记，成功使用密码不算内容修改。导出文件之后是否被移动或删除无法由本机记录证明。
清理安装包删除历次更新遗留的程序缓存安装包；当前尚待安装的准备包和被占用文件暂时保留。重启后不再被本会话准备状态保护的旧包可以清理。
仍需用户确认最终视觉与实际体验；本机未运行桌面自动化或替换真实安装。物理混合 DPI、真实系统高对比切换和交互式读屏不冒充自动检查完成。
