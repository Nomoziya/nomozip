# 创建压缩包与 Windows 文件入口

在“压缩”页添加文件或文件夹，也可直接拖入。右键源列表可添加或移除内容；选中源后也可按 Delete 移除。选择 7z/ZIP、压缩级别和完整保存位置，再点击“创建压缩包”，快捷键为 Ctrl+Shift+C。选中的内容以各自名称进入压缩包，文件夹保留内部结构；空文件与空文件夹支持保留。同名但来自不同位置的内容会被拒绝，避免混淆覆盖。当前不跟随链接或目录联接点。

勾选“使用密码加密”后，可设置密码或选择密码库中的条目。7z 使用官方引擎加密，并可加密文件名；ZIP 使用 AES-256。当前官方 ZIP 写入接口仅支持 ASCII 密码，含中文等字符时明确拒绝，用户可改用 7z。密码从私有管道传到 DLL 的密码回调，不进入命令行、环境变量或设置文件。

用户可以选择压缩成功后保存新密码。新包通过完整测试后才保存密码或更新已有密码的关联；随后可自动复用该密码解压新包。取消或失败不保存密码。压缩先写同目录的独立临时文件，再由官方引擎完整测试，成功后才保存或替换目标；覆盖已有目标需要明确确认。失败与取消清理自己的半成品，保留原压缩包。

Windows 入口在“设置”中按需启用，为当前用户登记 7z/ZIP/RAR 的“打开方式”选项。默认应用由用户在 Windows 设置中选择。关闭入口及卸载只清理属于本程序路径的登记，保留其他副本与其他应用的入口；不改写已有默认应用。入口的实际显示与默认选择仍需在真实 Windows 桌面人工验收。

压缩兼容性验证同时覆盖官方 26.04/26.03：普通与加密 7z/ZIP、文件名加密、Unicode 路径、空内容、官方 CLI 逐字节读取、存储/最高级别、错密、取消、同名路径与输出保护。官方 CLI 的参数仅使用测试代码中的虚构密码。桌面验证通过实际按钮的 UI Automation 调用创建加密包、保存密码，再自动解压；另外核验标签、可获焦控件及快捷键绑定。这些检查不等同于 Narrator 或真人键盘验收。

后续官方引擎候选版本必须同时通过解压与压缩矩阵，才会启用。维护签名工具现在要求两类报告均通过、对应 DLL 哈希一致，并将压缩证据一并放入签名的兼容性报告。已发布的旧引擎资产保持不变。
