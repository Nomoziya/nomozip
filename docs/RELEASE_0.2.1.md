# nomozip 0.2.1

本版集中改进列表操作与视觉反馈，保留 0.2.0 的压缩、密码库、队列及重启续作功能。

- 解压任务、压缩源文件和密码库支持右键操作；右键先选中目标行，不可用操作及多余分隔线自动隐藏。
- 双击或 Enter 浏览压缩包、编辑密码，Delete 移除选中项。压缩源列表支持 Delete 移除；也可使用菜单键或 Shift+F10 打开列表菜单。
- 精简解压与密码库工具栏，保留添加、浏览、导入/导出及任务队列入口；导航增加图标，统一列表悬停、选中及按钮反馈。
- 列表焦点改为细线围绕整行，不再单独圈住文件名单元格；“解压规则…”改为轻量次要入口；调整浅色控件边界与深色错误文字，满足既有对比度标准。
- 小窗口中快捷键说明与数量共用一行，避免状态提示出现时挤占列表首行；完整说明可悬停查看。
- 修复英文侧栏底部说明被截断，按可用宽度自动换行。
- 简体中文和英语同步更新。没有新增运行依赖，继续只提供共享运行库轻量版。

## 下载与升级

从 [0.2.1 发行页](https://github.com/Nomoziya/nomozip/releases/tag/v0.2.1) 下载对应架构的安装 EXE 或程序 ZIP。支持 Windows x64 / ARM64，需要对应架构的 .NET 10 Windows Desktop Runtime（10.0.12 或更新的 10.0 补丁版）。

关闭软件后运行安装器可保留密码库与设置；ZIP 请解压到新的空目录。升级前请先完成或丢弃已有的保留任务。引擎独立更新渠道保持不变。

本版不增加功能范围；限制与数据保护说明沿用 [0.2.0 发行说明](RELEASE_0.2.0.md)。真实多屏受设备限制，讲述人发声仍属可选体验。

双架构完整功能、数据迁移和隔离安装升级验证通过；最后的焦点与入口调整另经双架构三主题、中英双语及缩放回归验证。详细源码范围和报告见[验收记录](ACCEPTANCE.md)。
