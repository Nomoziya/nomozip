# nomozip 0.3.0

本版采用全新的Windows桌面界面，保留原nomozip主图标，统一Fluent功能图标、字体、间距与浅深色主题。

- 文件浏览、包内图片/文本预览和解压操作集中到同一工作区，名称/大小排序、选择、长路径和窄窗口显示统一。
- 独立任务区域显示处理进度，圆环、进度条和百分比同步；暂停与减少动态效果设置保持一致。
- 密码库提供真实的已解锁/已锁定状态及锁定/解锁入口；最近成功时间按今天、昨天、日期显示，完整时间保留于提示。
- 新建压缩包、密码库、校验工具、设置与核心弹窗使用统一组件；简体中文和英语同步覆盖，保留系统高对比支持。
- 保留压缩解压、密码库与主密码、分组/备份、队列和续作、分卷与自解压、校验、格式转换、包内编辑与拖出、右键菜单和命令行功能。

## 下载与升级

提供Windows x64 / ARM64的安装EXE、程序ZIP及统一源码ZIP；仅提供共享运行库轻量版。需要对应架构.NET 10 Windows Desktop Runtime（10.0.12或更新10.0补丁版）。

关闭软件后运行安装器升级，保留本机密码库与设置。ZIP解压到新的空目录。升级或切换架构前，请完成或丢弃已有的保留任务。软件与引擎继续使用原有独立更新渠道。

## 验证范围

正式发布以前执行双架构完整功能、安装升级/卸载与注册表、传统Shell集成、数据迁移及当前界面回归。结果与具体来源记录在[当前状态](CURRENT_STATE.md)。物理多屏、设备实际缩放和讲述人发声不冒充隔离CI验收。
