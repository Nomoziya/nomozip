# 将包内所选内容拖到文件夹

候选版本：0.2.0-preview.27。沿用 WPF、系统 OLE 拖放与官方 7-Zip 引擎，不增加运行组件。

## 操作

1. 添加压缩包，打开“查看内容”。
2. 勾选文件或文件夹，再按住任一文件名向目标文件夹拖动。没有勾选时，使用当前高亮项；勾选范围包括被搜索隐藏的项，目录包含后代。
3. 软件先在当前资料目录的 `drag-temp/<随机编号>` 中解压准备。大文件需要等待，可取消。保持按住鼠标时，准备完成后直接进入系统拖放；如果已松开，则提示“已就绪”，再次拖动文件名即可。
4. 也可在“内容操作”菜单中选择“准备拖出所选内容”，待就绪后再拖动。取消准备或关闭内容窗口会清理已准备的文件。键盘或单击操作可继续使用原有“解压所选”。

保留包内目录结构。例如只选 `folder/a.txt`，拖到桌面后得到 `folder/a.txt`，不会自动摊平为 `a.txt`。顶层同名冲突由接收程序处理，不套用主解压页的覆盖选项。

## 密码与任务

复用官方引擎的选择性测试/解压、逐条密码和现有文件名编码。自动尝试密码库；手动密码对话框不提供保存。准备和拖放均不保存新密码、不更新成功时间/关联，不改变整包完成状态或主解压结果目录。源压缩包只读；准备期间持有只读共享锁。

准备的文件带原有下载来源标记（文件系统支持时），既有不支持/读取失败策略保持。仅提供复制效果，不提供移动或删除原压缩包的行为；结果由目标程序处理，软件不冒称已逐字节验证外部目标。

## 临时文件生命周期

拖放数据只导出同步 COM `IDataObject` 的 `CF_HDROP` 绝对路径，不导出 `IDataObjectAsyncCapability`。按 [Microsoft Shell 同步/异步数据传输约定](https://learn.microsoft.com/en-us/windows/win32/shell/datascenarios#dragging-and-dropping-shell-objects-asynchronously)，同步接收程序在 `DoDragDrop` 返回前完成读取，返回后清理当前准备目录。拒绝目标、Esc 取消和拖放错误也清理。临时目录清理失败时，在内容窗口和主界面显示实际路径；当前窗口保留取消清理的重试状态，关闭后仍可按路径手动处理。

长时间的同步目标复制可能阻塞拖放循环；大批量解压仍推荐原有“解压所选”，其进度和取消由软件控制。目标若自行违规异步读取普通路径，不属于本协议支持的接收方式。临时文件不是安全擦除；进程崩溃、断电或被强制结束可能留下准备文件，未宣称这类情形自动清理。

## 验收

`tests/DragValidation` 使用 26.03 / 26.04 真实引擎检查文件/目录/空目录、层级与精确字节、固实加密、自动和手动密码、混合密码 ZIP/RAR5、无效快照、取消、来源标记、清理失败/重试，以及源文件和 APV1/APV2 密码库保持不变。

`--validate-drag-out <项目目录>` 使用隐藏合成资料检查生产浏览入口、实际菜单绑定、搜索隐藏的勾选范围、未勾选高亮项、双语言与三种主题的 900×600 / 640×400 / 512×360 布局、原生 `CF_HDROP` 解码并复制至自有目标、COM 不导出异步接口、原生 OLE 取消、关闭等待及临时目录清理。原生取消测试只向自己的线程投递消息，不移动桌面鼠标。

报告为 `artifacts/drag-validation.json` / `drag-ui-validation.json`，截图在 `artifacts/drag-preview`。实际 Explorer 鼠标拖放、外部目标的冲突弹窗和物理多屏体验未由隐藏测试替代。
