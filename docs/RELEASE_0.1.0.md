# nomozip 0.1.0 · 首个正式版

nomozip 是 Windows x64 压缩包工具，使用官方 7-Zip 引擎，保存你提供的解压密码并在下次自动尝试。

- 本机加密密码库，支持添加、编辑、搜索、删除及自动尝试；缺少密码时手动补充，完整解压成功后才保存新密码。
- 7z、ZIP、RAR/RAR5 内容浏览和解压；传统 ZIP、AES ZIP、RAR5 的同包多密码组合解压经过专项验证。
- 创建 7z/ZIP，选择压缩级别和加密；7z 支持文件名加密，ZIP 创建密码当前仅支持 ASCII。
- 解压与压缩采用一致布局，密码库紧凑展示；修复任务文件名朗读、键盘焦点框裁切和极小工作区的操作可达性。
- 官方引擎候选兼容性检查、经本产品签名验证的引擎更新与回退，以及可选 Explorer 打开方式入口。

仅提供轻量安装 EXE 和 ZIP，软件目录约 9 MB；需要系统共享的 [.NET 10 Windows Desktop Runtime x64](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)（10.0.12 或更高的 10.0 补丁版），无需 SDK。约 9 MB 不包括共享运行库占用。

已有预览版：关闭 nomozip，使用安装器覆盖升级，保留密码库、设置和已下载的引擎。ZIP 解压到新的空目录；卸载默认保留本机数据。添加打开方式入口不直接更改默认应用，Windows 可能询问使用哪个程序，由你选择。

用户已确认布局、压缩加密与自动解密、键盘操作、系统对比度，并完成焦点框和任务文件朗读复验。旧密码库保留/复用、缩放布局和完整业务流程由代理检查；实际不同 DPI 多屏切换仍未实测。安装包暂未使用 Authenticode 证书签名。验证记录见[验收说明](ACCEPTANCE.md)。

发行资产：轻量安装 EXE、轻量 ZIP、源码 ZIP、`SHA256SUMS.txt`。软件正式版与签名引擎更新包分别发布；本次使用 `v0.1.0`，历史发行资产保持不变。
