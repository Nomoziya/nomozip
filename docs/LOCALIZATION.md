# 界面语言

F15 开发与代理验收完成，版本为 0.2.0-preview.21，仅准备本地候选。首期为简体中文和英语；默认保留简体中文，在设置中保存语言，重启后生效。本期只提供共享运行库轻量候选，旧完整包仅作升级兼容性夹具；公开正式版仍为 0.1.0。

文案使用 .NET 自带的 `.resx` 与 ResourceManager，英语使用卫星资源程序集，不引入运行依赖。键与语言文本分开；文件路径、用户密码名称/备注、密码内容、协议状态码及归档内名称不作为翻译输入。语言偏好独立保存，不改旧设置版本或密码库格式。非法或不支持的语言回退中文，不能以回退为由覆盖原偏好文件。

实施顺序：审计与抽取、双语资源和启动偏好、设置入口、实际页面/对话框及数据检查、轻量包与交接。现有中文默认行为和测试保留；英语需要真实 WPF/UIA、长文案及高对比度检查，不能只检查翻译文件存在。

用法：设置 → 界面语言 → 选择 English 或 简体中文 → 保存语言，完成当前工作后重启。偏好保存在用户数据目录的 `ui-language.json`，与原 `settings.json`、密码库分开。日期继续沿用列表中的 `yyyy-MM-dd HH:mm` 数字格式；普通数值格式使用选定语言的文化设置。用户文件名、备注、密码等不翻译。原资源迁移保留稳定键，新增文案优先使用有意义的键，并同时更新两份 `.resx`；格式占位符必须一致。

安装向导使用 [NSIS 标准语言选择](https://nsis.sourceforge.io/Docs/Modern%20UI%202/Readme.html)，独立记忆中英文选择，卸载沿用；它不会改应用内偏好。应用首次仍为中文，英文指南另放 `README.en.txt`。安装升级验证分别指定中文首装、英语升级，检查语言登记与旧数据保留，不把静默安装当作人工安装向导体验。

本地资源/偏好 37 项、两种语言的真实 WPF/UIA 各 74 项、独立进程重启 4 项通过；每种语言 46 个截图样本，含四页、十五种对话框/状态、普通/高对比度与窄窗。实际两版引擎加密压缩、保存 Unicode 密码和自动解密通过。产品源码 `70185489fba0e278035bac83927010bd0c5ec724` 的完整 [x64 CI](https://github.com/Nomoziya/nomozip/actions/runs/38685093353) 和 [原生 ARM64 CI](https://github.com/Nomoziya/nomozip/actions/runs/38685102209) 全部通过；68 / 67 份报告的集合、逐项结果和十矩阵维护的 17 项文件绑定摘要复核通过，两架构安装升级各 23 项通过。既有密码库、压缩/解压、队列/暂停、格式、更新及传统菜单回归保留。UIA 检查可访问名称，不等同于实际讲述人发声验收。

本地 x64 载荷 10670501 字节 / 47 文件，比上一候选增加 174967 字节；新增文件只有英语卫星资源与英文指南，依赖图没有新增运行组件。原生 ARM64 载荷 7481057 字节 / 33 文件，安装器 1869987 字节；原生程序来自上述 ARM64 CI，在本地 x64 机器只检查 PE、CRC、SHA-256 和源码一致性，不宣称本地原生执行。最终轻量资产分别位于 `artifacts/release-0.2.0-preview.21-final/` 与 `artifacts/release-0.2.0-preview.21-arm64-final/`，包外同名 `-validation.json` 记录独立复核；ARM64 安装器与载荷保留 CI 原字节，交接源码共用完成文档的最新快照。未替换实际安装、覆盖旧包或公开发行。

传统 Explorer 菜单的文案在登记时生成。切换应用语言并重启后，如需更新现有菜单语言，请在设置中移除、重新添加菜单；应用不会为切换语言而自动改写注册表。

首轮 x64 / ARM64 CI 的并发检查在填写密码弹窗时失败。已用同一 .NET SDK 的最小资源项目复现：LF/CRLF 源码检出会使嵌入资源的换行分别为 LF/CRLF；旧测试按 LF 拆分描述文字，拿到了末尾带回车的文件名。文案读取现统一 LF，保持迁移前 C# 字符串语义；测试从已有文件名输入框读取身份，不再解析显示文案。真实双任务、口令隔离、密码保存和输出内容标准不变，最终两架构完整回归已通过。被最终修复替代的中间 CI 已取消，没有把取消结果当作通过。

首轮 ARM64 安装检查的 23 项均为真，但新增两项语言记忆检查后仍要求旧的 21 项总数，导致总结果误判失败；现修正为轻量版 23 项。语言偏好未知版本的界面保存另补错误提示和原文件保留检查，避免未处理异常；测试完成后恢复自有偏好文件，再由独立进程检查重启切换。没有读取真实密码库或更改实际安装。

参考：[.NET 资源读取](https://learn.microsoft.com/en-us/dotnet/core/extensions/retrieve-resources)、[资源打包与部署](https://learn.microsoft.com/en-us/dotnet/core/extensions/package-and-deploy-resources)。现有设计规范和 ui-ux-pro-max 的 WPF 表单、辅助技术和溢出处理规则继续适用。

本期不增加运行中语言切换、云翻译或新的主题。第三方系统对话框和官方自解压模块的语言由 Windows/官方组件决定；应用负责自身的标签、提示与可访问名称。
