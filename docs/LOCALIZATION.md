# 界面语言

F15 实施中。用户确认首期为简体中文和英语；默认保留简体中文，在设置中保存语言，重启后生效。安装和测试仅使用共享运行库轻量包。

文案使用 .NET 自带的 `.resx` 与 ResourceManager，英语使用卫星资源程序集，不引入运行依赖。键与语言文本分开；文件路径、用户密码名称/备注、密码内容、协议状态码及归档内名称不作为翻译输入。语言偏好独立保存，不改旧设置版本或密码库格式。非法或不支持的语言回退中文，不能以回退为由覆盖原偏好文件。

实施顺序：审计与抽取、双语资源和启动偏好、设置入口、实际页面/对话框及数据检查、轻量包与交接。现有中文默认行为和测试保留；英语需要真实 WPF/UIA、长文案及高对比度检查，不能只检查翻译文件存在。

用法：设置 → 界面语言 → 选择 English 或 简体中文 → 保存语言，完成当前工作后重启。偏好保存在用户数据目录的 `ui-language.json`，与原 `settings.json`、密码库分开。日期继续沿用列表中的 `yyyy-MM-dd HH:mm` 数字格式；普通数值格式使用选定语言的文化设置。用户文件名、备注、密码等不翻译。原资源迁移保留稳定键，新增文案优先使用有意义的键，并同时更新两份 `.resx`；格式占位符必须一致。

安装向导使用 [NSIS 标准语言选择](https://nsis.sourceforge.io/Docs/Modern%20UI%202/Readme.html)，独立记忆中英文选择，卸载沿用；它不会改应用内偏好。应用首次仍为中文，英文指南另放 `README.en.txt`。安装升级验证分别指定中文首装、英语升级，检查语言登记与旧数据保留，不把静默安装当作人工安装向导体验。

当前本地资源/偏好 35 项、两种语言的真实 WPF/UIA 各 72 项、独立进程重启 4 项通过；每种语言 46 个截图样本，含四页、十五种对话框/状态、普通/高对比度与窄窗。实际两版引擎加密压缩、保存 Unicode 密码和自动解密通过。原中文更新界面检查通过；完整 x64 / ARM64 CI、安装升级及最终轻量包复核仍待完成，不提前计为 F15 完成。

参考：[.NET 资源读取](https://learn.microsoft.com/en-us/dotnet/core/extensions/retrieve-resources)、[资源打包与部署](https://learn.microsoft.com/en-us/dotnet/core/extensions/package-and-deploy-resources)。现有设计规范和 ui-ux-pro-max 的 WPF 表单、辅助技术和溢出处理规则继续适用。

本期不增加运行中语言切换、云翻译或新的主题。第三方系统对话框和官方自解压模块的语言由 Windows/官方组件决定；应用负责自身的标签、提示与可访问名称。
