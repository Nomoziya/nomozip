# nomozip 0.3.4

本版整合已验收的浏览、压缩和预览功能，并改善任务详情与短窗口阅读。

- 包内搜索可选择整个压缩包或当前目录及子目录，并定位到原条目；隐藏选择数量始终明确。浏览视图、排序和列宽可记忆，也可重置布局。
- 压缩支持保存非密码参数方案、按目录名/扩展名排除、创建前内容预览，以及每来源分别压缩。失败后可按原参数重试或修改后创建，旧输出按编号保留。
- 预览可按打开时的筛选和排序切换前后文件；文本支持 Ctrl+F、F3/Shift+F3，关闭后取消读取。
- 密码库可试算已保存规则的实际尝试顺序，显示关联、目录、文件名和成功历史；不显示或验证密码，不写入密码库。
- 任务支持紧凑/舒展密度与按需详情；完整错误换行，窄窗操作重新排列。压缩状态和密码匹配理由更易阅读，区分计划输出与实际结果。
- 大列表搜索、排序采用后台计算，网格采用虚拟化；减少压缩排除匹配的临时分配。效果取决于机器和输入，不承诺所有归档均更快。

公开附件只有 Windows x64 / 原生 ARM64 安装 EXE 和 SHA256SUMS.txt。需要对应架构的 .NET 10 Windows Desktop Runtime（10.0.12 或更新的 10.0 补丁版），无需 SDK。关闭软件后运行对应安装器升级；升级和默认卸载保留密码库与设置，建议先导出加密备份。软件与引擎发行渠道保持原设置。
