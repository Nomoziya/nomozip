# 图标与界面修整

F28 / F29，preview.29。本轮保留 WPF、既有命令、密码处理和轻量共享运行库路线。

## 0.2.1 列表与主题改进

解压任务、压缩源与密码库共用右键菜单行为：先选中指针所在行，再显示当前可执行操作；没有可用操作的分组与多余分隔线隐藏。解压与密码库保留双击 / Enter 主操作、Delete 移除，压缩源支持 Delete。导航增加矢量图标，紧凑窗口仍优先保留文字；列表选中状态和按钮悬停共用动态主题资源。

发布复核按用户反馈改为整行内部焦点提示，与文件名保留间距，避免单元格边线挡住文字；“解压规则…”使用无常驻边框的次要操作样式，并校正浅色控件边界及深色错误文字的对比度。现有视觉验收扩展到每语言124项，新增右键目标、快捷键、动态菜单、焦点与配色检查。侧栏底部说明按实际宽度换行，避免英语说明被截断。没有新增依赖，保留所有既有密码和任务处理逻辑。历史预览的证据与说明见下文；当前发行状态以 [0.2.1 说明](RELEASE_0.2.1.md) 为准。

## 图标

蓝色折角文件、白色 N 和拉链组成 nomozip 自有标识。可编辑矢量母版为 `assets/nomozip-mark.xaml`；在 Windows 中运行 `scripts/build-icon.ps1` 可重新导出 16、20、24、32、40、48、64、128、256 像素透明 ICO 及 256 像素 PNG。图形由项目自行绘制，没有使用 7-Zip 或其它产品商标。

EXE、窗口和安装/卸载程序使用同一 ICO；侧栏使用同源高分辨率 PNG，通知区从当前 EXE 提取图标并在释放时销毁自有句柄。既有打开方式的 DefaultIcon 仍指向程序的第一个图标；本地验证不修改注册表。Windows 图标缓存可能延迟刷新；真实 Explorer、通知区显示与任务栏观察仍属于系统体验。

## 界面

- 任务与内容操作菜单共用完整表面、菜单项、分隔线和内部焦点样式，移除默认图标侧栏；保留 MenuItem / Command / UIA 语义和禁用状态。
- 设置卡片的阅读宽度最多 920 DIP。语言、主题、引擎、空闲锁定等短选项统一为紧凑的 260 DIP 左对齐字段；完整设置仍可垂直滚动。
- 打开方式的三个按钮在水平、垂直方向都保留间距；解压工具栏换行时保留行间距。
- 主页面卡片共用轻分隔边界和既有动态主题。复选框长文字保留访问键并自动换行，修正英语自解压选项被截断的问题；压缩格式/级别共用标签行，长标签换行后两个下拉框仍对齐，分卷标签保留独立间距。

## 自动检查与体验范围

运行 `scripts/test-visual-refresh.ps1 -ApplicationDirectory <专用候选目录>`：用人工示例数据在隐藏窗口中分别检查简中和英语，每种语言 124 项，覆盖三种主题、800 / 1120 / 1600 DIP、200% 渲染样本、设置换行和菜单真实命令调用。报告和截图保存在 `artifacts/visual-refresh/<语言>/`。渲染缩放不等于物理 DPI 切换；UIA 不等于讲述人真实发声。

原有可访问性和显示布局检查继续保留。完整功能、安装升级与注册表仅在一次性 CI 中执行；本地不安装候选、不读取生产更新私钥；0.2.1 发行授权及证据见[验收记录](ACCEPTANCE.md)。按2026-10-16用户决定，F23真实多屏/物理混合DPI因没有第二块屏幕记录“设备受限，未实测”，不阻挡当前自用版本；讲述人实际发声体验为可选。Explorer、任务栏、通知区等其它真实体验保持原范围。详见 [当前系统验收范围](SYSTEM_ACCEPTANCE.md)。
