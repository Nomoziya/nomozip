# 选择性解压

开发候选 0.2.0-preview.5 在“查看内容”窗口增加范围选择。公开正式版保持 0.1.0。

1. 在解压页选择压缩包，点击“查看内容”。文件名加密时先输入查看密码，浏览本身不输出或保存密码。
2. 勾选文件或文件夹；文件夹会包含全部子项。可以搜索并“选择可见项”，选择跨搜索保留。底部明确显示勾选数量与展开后的实际范围，隐藏项也包含在数量内；“清空选择”清除全部选择。
3. 点击“解压所选”。使用主页面的输出位置、目录规则、同名文件策略和自动尝试密码设置，保留包内目录结构。
4. 成功后显示结果位置，可打开结果目录。只将所选范围记录为完成，不把整个压缩包任务标成“已解压”；此前已完成的整包状态保持。底栏打开目录优先使用最近成功的所选结果。

所选加密条目可复用密码库，也可手动补充。ZIP/RAR5 的所选多密码组合仍按条目验证，只有选定范围实际写入成功后才保存或记录使用过的密码。取消、校验失败和冲突取消不保存本次新密码。关闭正在处理的内容窗口会取消并等待结束，避免遗留工作进程。空文件夹可选择并保留。

选择会携带条目编号、路径、大小、目录和加密属性，工作程序每次打开时核对。若列表形状改变，会要求重新查看内容，不把旧编号套用到不同条目。空选择、重复编号或越界编号不会退化为整包解压。此检查不是对整个压缩包字节内容的锁定。

实现使用官方 SDK 的 [IInArchive::Extract](https://github.com/ip7z/7zip/blob/main/CPP/7zip/Archive/IArchive.h) 排序编号接口。固实包可能仍需解码同一数据块中的其它内容；只为选定范围建立输出流、统计结果和记录加密条目证据。使用独立的 `test-selection`/`extract-selection` 操作，旧工作程序会拒绝未知操作，避免忽略选择参数后解压整包。既有整包操作和引擎协议版本保留。
