# nomozip 0.3.3

本版增加更新后的安装包自动清理、下载状态反馈、包内高级筛选和密码来源目录优先规则，沿用现有界面。

- 设置→更新可选择在更新成功后的首次正常启动清理旧安装包，默认开启。只处理软件专用缓存，保留占用文件及其它下载；可关闭并保存设置。
- 软件和引擎下载显示已下载量、速度与停滞提示，失败或取消后可重新下载，完整校验后才允许安装或启用。
- 包内高级筛选支持扩展名、MiB 大小范围和文件/目录类型组合。隐藏的已选条目仍属于提取范围，界面会提示；进入目录时清除全局筛选。
- 密码可设置优先匹配的来源目录，包含子目录。目录规则或文件名规则匹配即可优先尝试，仍保留其它密码候选和成功关联优先级。
- 大列表搜索采用批量更新、排序复用和输入延迟；英语数量文案按各自计数使用单复数。

公开附件只有 Windows x64 / 原生 ARM64 安装 EXE 和 SHA256SUMS.txt。需要对应架构的 .NET 10 Windows Desktop Runtime（10.0.12 或更新的 10.0 补丁版），无需 SDK。关闭软件后运行对应安装器升级；升级和默认卸载保留密码库与设置，建议先导出加密备份。软件与引擎发行渠道保持原设置。

## 验证与资料

功能与界面验证沿用候选589e24b：[x64新流程](https://github.com/Nomoziya/nomozip/actions/runs/39389922372)、[原生ARM64产品](https://github.com/Nomoziya/nomozip/actions/runs/39391092871)、[x64引擎补测](https://github.com/Nomoziya/nomozip/actions/runs/39391099970)。发布阶段另做0.3.3版本打包及正式0.3.2载荷升级/卸载检查；安装器使用隔离验证封装，不在用户本机安装。

性能不是全面提升：相同本地ViewModel十万条目单次样本搜索383→172ms、目录导航48→27ms，打开95→260ms、排序307→353ms。预排序增加首次打开成本，单次采样受JIT影响，不能当作所有归档都更快。原始数据与最终真实WPF界面采样见[实际原图验收](../design-system/reference-20261017/post032-20261020/index.html)。

[UI规范](UI_STYLE_GUIDE.md)、[密码规则](PASSWORD_ORGANIZATION.md)及[当前状态](CURRENT_STATE.md)保留完整范围与证据。物理混合DPI、多屏、真实系统高对比切换和交互式读屏尚未独立验收。
