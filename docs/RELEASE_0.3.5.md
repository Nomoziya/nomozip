# nomozip 0.3.5

本版保留0.3.4的浏览、压缩、预览与UI改进，补齐“定位所在目录”菜单项缺少的图标，使其与其它菜单及主题保持一致。

0.3.4的双架构发行、正式0.3.3升级和公开下载均已通过，但发布后的完整页面回归发现该菜单图标遗漏。0.3.5在发布前补验完整双语产品页面，再核对从正式0.3.4升级、安装器和公开下载；0.3.4原资产保留。详细功能见[0.3.4发行说明](https://github.com/Nomoziya/nomozip/releases/tag/v0.3.4)。

公开附件只有Windows x64 / 原生ARM64安装EXE及SHA256SUMS.txt。需要对应架构的.NET 10 Windows Desktop Runtime（10.0.12或更新的10.0补丁版），无需SDK。关闭软件后运行对应安装器升级；升级和默认卸载保留密码库与设置，建议先导出加密备份。软件与引擎发行渠道保持原设置。

完整验收、最终CI、冻结源码及公开下载结果以发行页最终记录和[当前摘要](https://github.com/Nomoziya/nomozip/blob/main/docs/CURRENT_STATE.md)为准。物理多屏、真实系统高对比切换和交互读屏未冒称执行。
