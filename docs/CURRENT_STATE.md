## 产品及约束

Windows WPF 压缩工具，使用官方 7-Zip 引擎，保存用户提供的密码并自动尝试。现有能力包括密码分组、独立加密备份、可选主密码/空闲锁定、压缩与加密、分卷/自解压、内容浏览/预览/编辑/拖出、选择解压、队列/并发/暂停、检查点续作、哈希校验、语言/主题、CLI、软件及引擎更新。

- 只提供共享运行库轻量版，支持 x64 / ARM64；不再发布捆绑 .NET 运行组件的版本。
- Windows 原生一级右键菜单公开启用及商业代码签名不在范围，保留传统菜单。
- 保留旧发行/候选、公钥、密码库和有效验收证据。生产更新私钥不可读取。
- 不替换本机实际安装、不读取用户真实密码库、不进行本机鼠标/键盘/WinAPI/UIA 桌面自动化；此前安全软件曾对桌面验收辅助脚本告警，不重建或放行该类脚本。
- 完整功能、安装升级及注册表检查仅在隔离 CI 执行；本地不用 GiB 级夹具。
- 物理多屏因用户设备受限未实测且不阻挡发行；讲述人实际发声为可选。不得把模拟渲染和 UIA 检查写成物理体验通过。
- 续作以完整文件为检查点，不保存密码；不支持文件内字节续传，固实包可能重新解码前缀。
- 软件事务回滚未实现，不应把引擎回退或检查点恢复描述为软件升级事务回滚。
