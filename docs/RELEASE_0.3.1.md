# nomozip 0.3.1

修复多处普通按钮在悬停或按下时文字、图标被底色遮挡的问题，包括校验清单导入、默认解压规则与密码库更多等操作。共享按钮模板改为在内容后方切换背景，正常布局、字体、尺寸与配色保持0.3.0采用稿。

提供Windows x64 / ARM64安装EXE、程序ZIP和统一源码ZIP，均为共享运行库轻量版。需要对应架构.NET 10 Windows Desktop Runtime（10.0.12或更新10.0补丁版）。关闭软件后运行安装器升级；ZIP请解压至新的空目录。

## 验证与样式依据

- 复用已通过的本次修复证据：x64中英文各180项真实鼠标/前景可见性检查；原生ARM64中英文各180项显式WPF状态渲染检查。覆盖浅色、深色、柔和和高对比资源及正常、悬停、按下、聚焦、禁用状态。
- 两架构中英文产品界面各476项、传统视觉各124项通过；正常尺寸6张核心截图与0.3.0逐字节一致。旧模板在相同条件下重现24个遮挡状态，保留为预期失败对照。
- 正式包另在隔离CI验证实际主流程、0.3.0升级/卸载与原生架构/包完整性；具体运行和结果以[当前状态](CURRENT_STATE.md)记录为准，未完成阶段不记通过。
- ARM64状态渲染通过不代表真实鼠标输入已通过；物理多屏、设备DPI切换和交互式讲述人仍未独立验收。
