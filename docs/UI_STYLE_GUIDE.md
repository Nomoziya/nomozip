# nomozip UI 修改入口

## 2026-10-22规范内扩展（实施中，待CI验收）

- 搜索结果列表主行显示文件名，次行显示目录；网格分开文件名主体和扩展名，目录为辅助文字，全路径可从提示访问。保留132 DIP卡片和虚拟化；512×360短窗收起网格大图标，保留28 DIP复选区域、卡片内边距4 DIP，名称/目录/大小/复选入口保留。短窗搜索范围控件28 DIP，常规34 DIP，与“仅看已选”同行换行，不得裁切第一条结果。
- 范围为整个压缩包/当前目录及子目录，仅看已选恢复全包。“更多→定位所在目录”清查询并选中、滚动到原条目，不改变选择/提取范围。
- 压缩增加可展开的内容排除区，默认无规则；独立异步预览可关闭以取消扫描。目录名任意层级精确匹配，扩展名匹配后缀；逐行显示包含/排除、实际包名、包内路径及源字节。排除目录不扫描子内容，创建重扫；固定底部摘要显示规则数或上次预览，源大小不是压缩体积。输入错误与创建禁用范围对应。
- 压缩失败的任务详情和菜单增加重试、修改后创建；按原参数重试不改压缩页草稿，修改入口明确会替换当前输入。原输出编号保留，状态说明来源重读及使用当前启用引擎；取消停止后续任务。短窗更多按钮仅图标，保留文字提示/可访问名称，减少工具栏换行以留出完整文件卡片。
- 连续预览沿用侧栏；前后切换及位置计数常驻内容标题下，按打开时筛选/排序快照并跳过不支持项，Ctrl+PageUp/PageDown。文本查找按需展开，Ctrl+F与F3/Shift+F3，Enter查找下一处、Esc收起，纯文字、不区分大小写、到末尾循环；保留高亮但不抢输入焦点。读取中阻止重复切换，关闭取消，错误后允许继续浏览。
- 密码库更多菜单增加“试算已保存规则”，选择归档后展示实际候选顺序、记录/分组及匹配原因，不展示密码、不验证或写库；已关闭自动尝试时明确该状态。长原因可水平滚动与提示查看；512×360保持列表和关闭入口。
- 入口：ArchiveBrowsingSearch/ArchiveContentsDialog、CompressionExclusions/CompressionSources、CompressionContentViewModel/CompressionContentsDialog。WPF及真实引擎检查未通过前不标为已验收；当前CI与失败修复只记录于CURRENT_STATE。

## P2规范内扩展（2026-10-21，候选完成待体验确认）

浏览布局保持现有视图按钮与列头，在更多菜单增加“重置浏览布局”，列宽拖动后记忆；默认列宽仍随窗口计算，用户主动指定宽列时允许水平滚动，窄窗沿用原隐藏列规则。保存全局列表/网格、类型排序字段/方向与列编号/宽度，不保存归档路径、搜索、选择；在归档关闭后保存，重置同时恢复列表、默认顺序和自动列宽。两枚视图按钮改为双向状态绑定，使UIA切换也更新实际视图。

压缩设置的方案选择下方增加“每项分别压缩”，默认关闭，不写入命名方案或自动恢复该模式。选中后名称框禁用并显示按来源自动命名，保存目录仍可编辑；帮助文字解释一来源一包与重名编号。固定结果区显示包数量与参数，创建按钮明确数量，主布局不变。输出目录须在所有来源文件夹之外，避免逐项产生的包进入后续来源；已有文件/分卷自动编号保留。逐项结果出现在既有任务列表，失败继续、取消停止后续并保留已完成；SFX、分卷与加密沿用现有验证流程，一批只提示一次密码，保存时关联同一个条目。[实际WPF原图与验收](../design-system/reference-20261017/usability-p2-20261021/index.html)已归档：b253572双架构中英新增流程各128项，视图/列宽/排序独立进程恢复、重置及分别压缩实际结果通过；116种画廊选择可加载。沿用1046ee2中英页面各477与按钮各180成功步骤，产品逻辑不变。候选与性能边界、设备待验收项以[当前摘要](CURRENT_STATE.md)为准，等待用户体验确认。

| --- | --- |

| 主色 | 浅色AccentBrush #006CD9，CanvasBrush #F3F4F6，SurfaceBrush #FFFFFF，TextBrush #111722；其他语义色及深色/柔和色取资源快照和ThemeResources |
| 控件 | 主操作胶囊36 DIP高，图标通常20×20，图文间8/10；输入框圆角4，焦点使用FocusBrush的2 DIP边框；间距以8/12/16/20/24为主 |
| 表单 | 短选项按当前文字自然宽度、最小80 DIP，保留箭头右留白；格式/级别同排、间隔20；路径/名称在最大640 DIP表单内弹性编辑；自定义数字128+间距8+单位90 |

| 状态 | 悬停、按下、禁用、键盘焦点沿用共享模板；表头使用独立矩形模板，不让焦点/选中背景铺满整列；高对比优先系统语义资源 |

| 长内容 | 名称/路径单行省略并提供完整提示；输入值保持可编辑；长说明换行；多条目纵向滚动。窄窗按现有页面断点隐藏次要列/收起预览，不压缩主要动作 |

按钮的悬停/按下背景必须位于文字和图标下方；共享模板直接更换承载内容的ButtonSurface背景，不能用不透明的上层覆盖层。状态验收需要真实鼠标进入、按下，以及最终截图中文字/图标的可见性；正常态或Content属性存在不能代替悬停验收。

小窗口标题区必须留出系统关闭按钮，并确保位于WindowChrome区域的搜索/操作接受客户区输入。详细阈值和留白见MASTER文首，原图在`regression-3a4a6cc/`。

## 复用位置与检查

- 通用字体、按钮、字段、列表、表头、焦点：`src/Desktop/App.xaml`。主题语义色：`ThemeResources.cs`。窗口/菜单：`WindowChromeResources.xaml`、`WindowChromeBehavior.cs`、`ActionMenuResources.xaml`。
- 页面：`MainWindow.xaml`及Workspace分部、`CompressionView.xaml`、归档浏览/预览、密码与主密码、校验和其他对话框。进度：`TaskProgressView`；图标：`FluentIcon`和`FileKindIcon`。
- 同一功能优先复用现有命令、ViewModel和资源，不复制固定宽度/颜色模板。检查空、典型、长路径、多条目、处理中、暂停、成功和失败等适用状态。
- 修改后在隔离CI运行受影响检查，以相同窗口尺寸、语言、主题、内容和状态截取实际软件图，和对应基准并排/必要时叠加。核对文字、字体、图标、颜色、间距、尺寸与输入状态；复用未变更的有效证据。禁止本机桌面自动化、读取真实密码库或替换实际安装。
