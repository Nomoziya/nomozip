# ZIP 文件名编码

当旧 ZIP 包内文件名显示乱码时，在解压任务列表选择该 ZIP，点击列表下方的“ZIP 文件名”。选择编码，点击“预览名称”，确认名称正确后“应用到此任务”。查看内容、校验、整包解压和所选内容解压均沿用这一选择。

可选项：引擎默认、简体中文 GBK / CP936、日文 Shift-JIS / CP932、DOS / OEM CP437、UTF-8 CP65001。默认不猜测编码；带 UTF-8 标记或有效 Unicode 文件名扩展的名称优先，手动选项不会强行改写这些名称。无法预览或尚未重新预览时不能应用，取消保留原设置。预览只读取名称，不输出文件或保存密码。

编码只作用于当前队列中的所选压缩包，不影响其它包，也不保存为全局默认；移除后重新添加或重新启动软件会恢复引擎默认。更换编码后需重新查看内容并选择条目，先前校验结果和完成状态清除；已有输出文件保留，后续解压仍遵循同名文件策略。任务行的文件大小后显示手动选择的代码页。

此入口用于 `.zip` 文件。其它格式沿用默认引擎行为；伪装为 ZIP 的其它格式无法应用。ZIP 的文件名编码与密码编码是不同事项，ZIP 创建密码仍限制为 ASCII，非英文密码请使用 7z。

实现复用官方 ZIP handler 的 `ISetProperties` / `cp` 属性。新工作程序为手动编码提供独立操作，旧工作程序会拒绝这些操作，避免忽略用户选择。新官方引擎启用前必须通过编码兼容检查。测试使用真实 GBK、Shift-JIS、CP437、无标记 UTF-8、UTF-8 标记和 Unicode 扩展 ZIP，检查列举、校验、完整及所选输出名称与实际字节；不宣称自动识别。
