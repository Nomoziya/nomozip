按用户明确要求，当前自用版本采用以下范围；下方历史清单中的旧等待要求以本节为准。

### 剩余一组：重启续作 / 丢弃

preview.30本地轻量ZIP位于 `artifacts/release-0.2.0-preview.30-final/nomozip-0.2.0-preview.30-light-win-x64.zip`；原生ARM64电脑使用 `artifacts/release-0.2.0-preview.30-arm64-final/nomozip-0.2.0-preview.30-light-win-arm64.zip`。这是本地候选，不是公开发行。将适合本机架构的ZIP解压到新目录，在该目录运行 `ArchivePassword.exe --data-dir "D:\nomozip-acceptance"`，始终使用同一测试资料目录；不要把原密码库复制进去。只使用测试文件和独立输出目录，无需安装或放行辅助脚本。

专用本地测试包：`artifacts/reboot-acceptance-fixture/nomozip-reboot-test.zip`，约27MiB，解压后约451MiB，共9603个文件；其中9600个合成文本文件每个48KiB。包内只有文本、说明和校验清单，不含程序/脚本。大量完整条目用于提供可暂停和保存的边界，实际耗时随设备变化，不承诺固定秒数。包外 `使用说明.txt` 给出完整步骤。

1. 勾选“保留解压进度”，添加测试ZIP并选新的空输出目录。开始后等待已保存条目数大于0；初始校验阶段还没有可续作记录。可先“暂停队列”留出操作时间，再点击“取消队列”并正常退出；开启保留进度后取消队列会保留检查点，停止后应显示“可续作 · 已保存”。仅暂停不算跨重启验收。
2. 保存其它工作后手动重启Windows，再打开同一候选，保持同一资料目录、原包和原输出位置。在任务菜单恢复，等完整输出。
3. 完整输出共有9603个文件。可在“设置 → 文件校验 → 文件SHA-256”导入输出目录中的 `PAYLOAD.SHA256SUMS.txt` 并计算/校验：9602项应全部一致，清单不包含它自身；此次私有检查点暂存应清理。
4. 用同一ZIP另建一次中断任务，换空输出目录；在已保存条目后停止。选择丢弃进度，先取消一次确认记录仍在，再确认丢弃；核对只清理本次进度/暂存，原ZIP、无关文件及之前的完整输出保留。细节见 [续作说明](EXTRACTION_CHECKPOINTS.md)。

仅需反馈重启恢复和丢弃是否通过，以及清单是否全部一致。多屏不要求准备设备，讲述人可跳过；不要重复已验收项目。一次完整输出约450MiB，保留两次输出约900MiB，另加测试包与少量记录；验收结束后可删除不需要的测试资料。

## 准备

1. 关闭正在运行的 nomozip，安装 [第九预览轻量 EXE](https://github.com/Nomoziya/nomozip/releases/download/v0.1.0-preview.9/nomozip-0.1.0-preview.9-light-setup-win-x64.exe)。如果已安装第九预览，无需重装。打开“设置”，确认版本为 `0.1.0-preview.9`。无需补测第八预览。
2. 查看自己的密码库和设置，确认原有记录仍在；反馈只需记录是否保留，不必提供密码或记录内容。
3. 用资源管理器把 `artifacts/system-experience-kit.zip` 解压到新的空文件夹。里面有 `普通测试.zip`、`密码测试.7z` 和本清单。两个测试包都只包含 `验收说明.txt`，正确内容为“nomozip 系统体验测试：解压成功。”。加密包同时加密文件名，测试密码为 `Nomozip-Test-2026`。
4. 在“解压”页先移除列表中的其它任务，避免同时操作自己的文件。“移除所选”只移除任务，不删除原文件。选择一个新的空文件夹作为输出目录，例如测试文件夹下的 `解压结果`。
5. 记下“自动尝试保存的密码”、讲述人、对比度主题、显示缩放和打开方式入口的原状态。键盘测试期间关闭“自动尝试保存的密码”；密码对话框里的“成功后保存到密码库”保持不勾选。

准备可以使用鼠标；以下键盘步骤尽量只用键盘。出现问题时记录步骤和实际结果即可，不必反复尝试。

## 1. 键盘与焦点

1. 在“解压”页按 `Ctrl+O`，在文件选择框中选择 `密码测试.7z`，按 Enter 确认。
2. 用 Tab 向前、Shift+Tab 向后移动焦点。检查添加文件、任务列表、输出目录、同名文件选项、自动尝试和开始解压等控件都有清楚的焦点标记；没有一直跳不出去的位置。导航获得焦点后，用方向键切换解压、压缩、密码库和设置，再回到解压页。
3. 按 `Ctrl+E` 开始解压，进入密码对话框。先不输入密码，按 Enter：应显示“请输入密码。”，焦点仍在可输入密码的位置。
4. 按 Esc：对话框关闭，任务取消，输出目录中没有 `验收说明.txt`。
5. 再按 `Ctrl+E`，输入 `Nomozip-Test-2026`，确保保存密码选项未勾选，按 Enter：任务应显示“已解压”，输出目录出现 `验收说明.txt`，打开后的文字与准备步骤一致。
6. 用 `Ctrl+O` 添加 `普通测试.zip`。在任务列表中选中这条任务，按 `Ctrl+L` 打开“查看内容”。搜索 `验收`，应能看到 `验收说明.txt`；按 Esc 应关闭内容窗口。

通过标准：快捷键执行正确；Tab 顺序可理解，焦点可见；Enter 可提交，Esc 可取消和关闭；密码错误提示后仍能继续输入。

## 2. Windows 讲述人（当前为可选）

1. 用 `Win+Ctrl+Enter` 开启讲述人。首次使用如出现介绍窗口，返回 nomozip 后再测试；快捷键不可用时可从 Windows“设置 → 辅助功能 → 讲述人”开启。
2. 在 nomozip 中用 Tab 移动焦点，检查“输出目录”“同名文件”“开始解压”和密码库的“搜索名称或备注”等控件有清楚的名称与角色朗读。
3. 为重新打开密码对话框，在解压页选中已经完成的 `密码测试.7z`，点击“移除所选”，再用 `Ctrl+O` 添加它，输出目录换成另一个新的空文件夹，例如 `讲述人结果`。已完成任务不会再次解压，重复添加同一路径也不会产生重复行，因此这一步需要先移除。
4. 保持自动尝试关闭，按 `Ctrl+E`。检查密码输入框被识别为密码控件；未选择“显示密码”时，隐藏的密码不应作为明文朗读。
5. 留空按 Enter，检查是否能听到输入错误提示，或能通过焦点导航找到它；随后输入测试密码并继续解压，检查按钮和任务状态是否可理解。保存密码选项仍不勾选。
6. 恢复讲述人原状态；原先关闭时，再按 `Win+Ctrl+Enter` 关闭。

通过标准：主要操作无需猜测控件含义；错误提示可发现；隐藏密码不会意外明文朗读。如果提示需要额外导航才能找到，请记录具体情况。

快捷键参考：[微软讲述人键盘命令](https://support.microsoft.com/zh-cn/accessibility/windows/narrator/appendix-b-narrator-keyboard-commands-and-touch-gestures)。

## 3. 对比度主题

1. Windows 11“设置 → 辅助功能 → 对比度主题”，记下原主题，选择一个系统提供的主题，点击“应用”。
2. 返回 nomozip，依次查看解压、压缩、密码库和设置。检查正文、按钮文字、选中行、当前导航项和 Tab 焦点都能辨认；检查输入框、滚动条、禁用按钮与可用按钮能区分。
3. 打开密码对话框和内容浏览窗口，检查文字、错误提示和底部按钮同样清楚。
4. 恢复原主题并应用；原来没有对比度主题时选择“无”。

通过标准：没有文字和背景同色、选中状态看不清或焦点消失。参考：[微软对比度主题操作](https://support.microsoft.com/zh-cn/accessibility/windows/change-color-contrast-in-windows)。

## 4. 显示缩放与窗口

1. Windows“设置 → 系统 → 显示 → 缩放”，记下原比例。依次测试系统下拉列表可选的 `125%`、`150%`、`200%`；没有提供的比例记为“不可用”，无需使用自定义缩放或强制注销。
2. 每个比例下，把 nomozip 窗口先放大，再缩到允许的最小尺寸。查看解压、压缩、密码库和设置；检查文字不重叠、控件不截断，底部主要操作仍可到达；较长的设置区域可滚动到末尾。
3. 打开密码对话框和“查看内容”，检查输入框、关闭/确认按钮可见或可滚动到达。
4. 有多个显示器时，可把窗口移动到另一块实际采用不同缩放比例的屏幕，再检查文字和按钮。当前没有第二块屏幕，记录“设备受限，未实测”，跳过跨屏步骤且不阻挡当前发行；不按通过填写。单屏缩放检查继续保留。
5. 恢复原缩放比例。

通过标准：每个可测试比例下都能完成操作；没有无法到达的按钮或严重裁切。参考：[微软调整文本与应用大小](https://support.microsoft.com/zh-cn/windows/更改-windows-中文本的大小-1d5830c3-eee3-8eaa-836b-abcc37d99b9a)。

## 5. Explorer 打开方式

1. 先在资源管理器双击 `普通测试.zip`，记下当前默认打开的软件；关闭它。记下 nomozip 打开方式入口原来是否启用。
2. nomozip“设置 → Windows 文件入口”，点击“添加打开方式入口”。
3. 在资源管理器右键 `普通测试.zip`，选择“打开方式 → nomozip”；如列表未直接显示，查看“选择其他应用/更多应用”。只选择本次打开，不勾选或点击“始终使用”。
4. 应启动或切换到 nomozip，并将这份压缩包加入任务列表。选中它，按 `Ctrl+L`，应看到 `验收说明.txt`。
5. 再双击 `普通测试.zip`。Windows 在新应用登记支持文件类型后可能弹出打开方式选择窗口；这不是默认应用已经被替换。核对“默认应用”仍为步骤 1 的原软件。如果希望固定保留原默认，选中原软件后点“始终”；仅临时打开则点“仅一次”。不要选择 nomozip 为默认，除非你本来就希望改变默认软件。
6. 返回 nomozip 设置，点击“移除本程序入口”。重新打开右键菜单，确认入口移除，原默认软件仍保留。菜单如缓存旧结果，可关闭并重新打开资源管理器窗口后检查。
7. 如果入口原来已经启用，测试后重新添加；原来未启用则保持移除状态。

通过标准：本次打开的文件正确传入软件；登记和移除入口不写入原默认应用设置；系统询问时显示原默认，最终选择由用户完成；测试结束恢复原入口状态。此前“不出现选择窗口”的预期不正确，已依据[微软 Windows 默认应用平台说明](https://learn.microsoft.com/en-us/windows/apps/develop/windows-integration/default-apps-platform)更正。
