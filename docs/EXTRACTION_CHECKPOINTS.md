# 解压跨重启续作

当前为 preview.28 开发候选，尚待完整双架构 CI 与最终本地交接；公开发行和实际安装保持原状。

在解压设置中启用“保留解压进度”，再开始解压。选项默认关闭，旧设置继续关闭。开启后，停止、退出或进程中断会保留已完整解出、通过引擎校验并保存检查点的条目；启动软件会把保留任务放回队列，状态显示已保存数量。选择任务后，在“任务操作”中恢复或丢弃；“开始解压”也会处理列出的待续作任务。关闭选项只影响新任务，不删除已有进度。

恢复继续使用记录中的实际输出目录、文件名编码和原引擎；当前活动引擎不需要切换。若原引擎不存在、字节不同或架构不同，会停止并保留记录。恢复前先恢复原组件，或明确丢弃后重新添加任务。其它新任务仍使用当前设置。保留任务不能通过“移除所选”或“移除已完成”静默删除记录；文件名编码在丢弃之前保持绑定。同名目标仍沿用当前询问/跳过/替换策略，已明确跳过的项目保持跳过。

保留期间，输出目录中的 `.nomozip-checkpoint-<编号>/files` 包含解密临时文件，占用磁盘空间；资料目录的 `extraction-progress/<编号>` 保存源文件路径、条目名、哈希、引擎/编码绑定和交付记录。它们不是加密密码备份；没有密码、主密码、库编号、命令行密码或解码器内存。需要密码时会重新尝试当前密码库或询问。普通删除不承诺安全擦除。完成或明确丢弃后清理本次私有目录，已交付文件、原包和无关文件保留；占用或权限错误会保留记录以便重试。

卸载前请丢弃不再需要的进度。默认卸载/升级保留资料目录和外部暂存；显式删除资料目录会丢失恢复索引，不会扫描外部输出目录自动删除暂存，可能留下需要手动清理的上述编号目录。移动安装/资料、跨架构切换或改变引擎时应先完成/丢弃任务。

## 续作粒度与持久约定

这是完整条目检查点，不是单大文件内的字节偏移续传。中断时未确认完成的文件从头解出，固实包仍可能为后续条目重新解码前缀；已经验证的输出不会被当作待解条目送回 worker。列表有零字节文件/空目录时也保存其完成状态。

首次复用原来的完整测试、密码候选和来源读取流程，记录列出及测试实际打开的源文件集合，包含数字分卷和引擎请求的附加卷。全部源文件按长度/SHA-256 绑定并在活动会话中持有只读共享锁；数字分卷还核对集合，缺少或新增卷会拒绝。恢复按原引擎和文件名编码测试剩余条目、核对完整条目快照和实际源路径。已完整确认且仅待交付时不需要再次询问密码。

worker 仅在完整条目成功后关闭并刷新输出，再发完成事件；托管方读取实际字节、核对长度、计算 SHA-256，写入小型追加日志并 `Flush(true)` 后才 ACK，worker 收到对应编号 ACK 才推进。清单使用同目录临时文件替换；恢复压实检查点时启用新日志代际，旧日志不会覆盖新快照。缺少换行的尾记录视为未提交。坏 JSON、重复/越界编号、非法路径或不支持的版本拒绝使用，不把损坏记录视为已完成。

恢复时重新计算已完成文件的字节哈希；丢失/损坏的暂存和没有持久完成凭据的片段不被信任，只把这些项目重新解出。提交文件前再核对哈希并持有只读句柄。交付前保存目标意图，再搬移文件并记录结果；在搬移后、记录结果前中断，可由目标实际字节恢复交付状态。目标已被修改且没有有效暂存时，只重解该项并重新进行同名决策。下载来源标记在交付前应用，恢复时保留文件修改时间。

主会话记录有独占所有权；checkpoint worker 在输出私有目录外层持有另一份独占写入锁，直到进程退出。新会话或丢弃必须先获得这份写入锁，不能与旧 worker 同时核对/删除。托管返回前等待 worker 退出；父输入管道 EOF 会取消 checkpoint worker 的读写/进度或 ACK 等待。与同进程内暂停功能独立。不保证硬件断电、文件系统损坏或不遵守刷盘的设备具有事务性恢复，不能把软件提交恢复说成磁盘事务。

密码成功记录仍只在整个任务交付成功后执行，且只使用当前进程实际验证的密码。此前中断进程的成功统计/用户未保存密码不会重建，避免为了统计而持久化秘密。新 worker 操作具有独立名称，旧 worker 会拒绝而不会静默当普通解压处理。

## 验证与维护

`tests/CheckpointValidation` 用小型真实压缩包、官方26.03/26.04，启动独立托管进程，在已持久保存条目的边界强制结束父进程，然后以另一个新进程恢复。断言只解剩余编号、旧文件的字节/时间戳、原生退出和写入锁、完整结果及限定清理；另有提交阶段中断与“已搬移但日志未写”的独立窗口。覆盖普通/固实/文件名加密/分卷、坏检查点和未提交片段、源改变/缺卷/新增卷、绑定、并发拒绝、取消/丢弃/占用、逐条不同密码 ZIP 和 RAR，并与独立官方 CLI 核对内容。进度目录逐字检查不含合成密码；失败/取消后的合成密码库保持原字节。不是整包重跑或重新建立内存对象的测试。

`DesktopCheckpointValidation` 通过实际中英文 WPF/UIA 命令检查启动重建、默认关闭和旧设置、绑定输出、恢复、拒绝与确认丢弃、完成清理和新设置保存。浅/深/模拟高对比主题，两尺寸分别核对滚动视口中的条目和选项可达性、固定主操作；屏幕外渲染不冒充真实讲述人、物理 DPI 或多屏体验。

完整回归、安装/注册表测试仅在一次性 x64/原生 ARM64 CI 执行。安装验收使用真实中断记录、追加日志、暂存及源文件哈希，检查升级、安装后离线操作、默认卸载和重装不会改变保留进度。引擎维护新增第13份 checkpoint 矩阵及工作进程绑定，签发前核对实际引擎 SHA 和目标版本覆盖；篡改该报告必须拒绝。原12份矩阵和现有真实性验证保持。
