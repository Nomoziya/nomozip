## 功能与流程盘点

| 流程 | 必要入口与能力 | 新设计必须保留的语义 |
| --- | --- | --- |
| 打开 / 浏览 | 选择归档、目录面包屑、筛选、名称/大小排序、列表/网格、勾选、当前行 | 高亮决定预览，复选决定解压/编辑范围；不能混淆 |
| 包内内容 | 文本与图片预览、文本编辑确认写回、图片交给系统查看器、拖出、添加/替换/删除 | 保留格式/大小边界、备份、陈旧内容拒绝、异步关闭和临时内容清理 |
| 解压 | 单个/批量添加、输出规则、冲突（含重命名）、密码自动尝试/手动输入、选择性解压 | 参数确认后再启动；取消和密码保存保持真实作用范围 |
| 创建 | 文件/目录列表、格式、加密、压缩级别、分卷、自解压、高级参数摘要、转换 | 不增加自由压缩参数；来源列表勾选只控制移除，全部来源参与创建 |
| 队列 / 续作 | 进度、排队、受控并发、全队列暂停/继续/取消、移序、结果、失败详情、跨重启续作 | 不虚构单任务暂停、速度或字节级续传 |
| 密码库 | 密码/分组/规则、自动尝试、可选主密码、空闲锁、加密备份/导入 | 保留遮罩和显示时机、选择/锁定/关闭清理；不接触真实库进行设计验收 |
| 工具 / 设置 | 哈希与清单、文件名编码、语言、主题、默认值、软件/引擎更新与回退 | 软件更新和引擎更新分开；高对比度遵循系统配对 |
