# 外观与深色主题

F16 实施与验收中。沿用现有 WPF 布局和语义颜色资源，提供跟随系统、浅色和深色；默认跟随 Windows 应用配色。在设置 → 外观选择主题并保存后立即生效，不需要重启。系统高对比度始终优先；关闭后恢复所选主题。

偏好单独写入数据目录的 `appearance.json`，版本 1、`Mode` 为 `system` / `light` / `dark`。首次不创建文件；未知版本、损坏或无法读取的文件回退跟随系统，保留原文件并拒绝覆盖。保存失败不切换当前主题。不改语言偏好、原 settings.json 或密码库格式。

深色覆盖主窗、各业务对话框、输入/密码框、下拉菜单（含可编辑目录）、复选框、表格与选中状态、进度和滚动条。保留原有控件语义、键盘操作和 UIA 提供者。系统对话框、安装向导和官方 SFX 使用相应 Windows/组件配色，不通过改全局系统设置实现主题。Windows 支持时以 DWM 标准属性请求深色标题栏；不重绘系统窗口框架。

采用 .NET 自带 DynamicResource 和 Windows 消息刷新已打开窗口，不引入主题库或整体切换 Fluent 样式。选择该方式是为了保留已验收的布局、控件尺寸和依赖体积。跟随系统只读取 `AppsUseLightTheme`，在本程序窗口接到设置/系统颜色变化消息时重新读取；验证在自有 HWND 注入设置消息，并模拟两种系统偏好，不更改用户真实 Windows 主题。

验证先做资源/偏好与两语言的真实 WPF/UIA；复用双引擎创建、保存密码、自动解密、四页/十五类对话框、普通及高对比度和窄窗样本，新增即时保存、重启、旧数据保留、未知版本/锁定写入、下拉选择/可编辑目录和对比度检查。界面截图需要人工图像复核，不能仅凭绑定值或资源文件存在验收。完整 x64 / 原生 ARM64 CI 和最终轻量候选尚待完成。

当前本地通过：偏好数据 19 项、每种语言深色与高对比度业务/布局 74 项、每种语言外观设置/控件 33 项、独立进程重启 4 项；745 条中英文资源的 37 项检查通过。每种语言复用 46 个主窗/对话框样本，另有控件、禁用状态和真实下拉弹层截图。截图复核发现显示名称模板未接入导致记录类型泄漏，已补 ItemTemplateSelector 和渲染名称断言；测试截图在复选框变化后等待布局再捕获。未以绑定值正确代替实际显示检查。

设计规则：正文/辅助文字、错误文字、主按钮与选区文字配对至少 4.5:1；交互边界与焦点至少 3:1，装饰分隔不承担控件边界。浅色保留原配色，深色使用同一蓝色语义与不同表面层级，高对比度映射实际 SystemColors。两种语言文案在同一 resx 体系维护。

参考：[WPF 原生主题能力](https://github.com/dotnet/wpf/blob/main/Documentation/docs/using-fluent.md)、[Windows 明暗主题与 DWM 标题栏](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-windows-themes)、[对比度主题设计](https://learn.microsoft.com/en-us/windows/apps/design/accessibility/high-contrast-themes)。实际讲述人发声、物理混合 DPI 多屏、真实 SMB 与可见通知的既有边界保持不变。
