## 实现边界

- 用户已明确授权将图 11 的冲突重命名和临时编辑写回纳入本轮。重命名仅改变输出文件名，不能覆盖已有或本包其他文件；“应用于后续冲突”只在本任务内有效，重命名路径写入续作检查点。临时编辑首轮支持可预览文本（不超过 1 MiB），内置编辑器保留编码及换行，确认后复用归档服务验证并备份原包；取消清理临时副本。实际文件变化后拒绝陈旧写回。二进制文件继续使用已有替换功能。
- 技术依据：复用本项目 ArchivePreviewService、ArchiveEditingService 和 ExtractionCheckpointStore；[Microsoft File.Move](https://learn.microsoft.com/en-us/dotnet/api/system.io.file.move?view=net-10.0) 的禁止覆盖移动用于重命名交付，[File.Replace](https://learn.microsoft.com/en-us/dotnet/api/system.io.file.replace?view=net-10.0) 用于现有校验后替换及原包备份，未引入外部编辑器依赖。
- 保留归档服务、密码库格式、引擎及更新协议、安装和 CLI；主要重排视图并复用现有命令。既有执行器限制如单个压缩作业不因视觉设计而扩展为新的并发承诺。
- 保留 Page 的旧内部编号以减少流程回归，对外导航独立映射；需要时为文件与工具增加编号。
- 归档浏览从模态窗口迁入工作区时必须明确异步关闭、取消和临时内容清理，不能提前释放引擎操作资源。
- 解压参数确认后才提交操作；批量任务保留各自 shell 目标与续作绑定，不能用公共路径覆盖它们。
- 胶囊形用于按钮、筛选；输入框/表格/菜单不全部胶囊化。浅深色采用图册语义色。图 13 v2 是柔和配色示意，系统高对比度仍按系统语义色动态配对。
- 图中的密度设置、虚构版本与未实现操作不直接加入。既有高级功能保持可达；不因迁移删除旧功能或降低验收。
- 本地不替换实际安装、不读真实密码库或生产私钥、不执行鼠标/键盘/WinAPI/UIA 桌面自动化；产品运行与完整流程在隔离 CI。既有自动任务保持暂停，不发布版本或改变更新渠道。
