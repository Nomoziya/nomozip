# nomozip 0.2.0

面向 Windows x64 和 ARM64 的轻量压缩工具，继续使用官方 7-Zip 引擎与系统共享的 .NET 10 Desktop Runtime。无需安装 .NET SDK，不分发捆绑运行组件的版本。

## 相比 0.1.0

- 密码库支持独立加密备份、分组、来源与重复整理，以及可选主密码和空闲锁定。
- 解压支持目录规则、选择包内条目、单项任务、队列重排、受控并发、暂停及可选完成通知；开启保留进度后，可在退出或重启后核对并恢复完整条目。
- 内容浏览增加文本与图片预览、拖出所选内容、修改已有 7z/ZIP 和格式转换；创建支持分卷、自解压包、TAR 与单文件 GZIP/XZ。
- 增加文件 SHA-256 与清单、ZIP 文件名编码、命令行入口，以及软件更新的下载校验和安装交接。
- 提供简体中文/英语、跟随系统/浅色/深色主题、统一的菜单与设置布局、产品图标和原生 ARM64 轻量包。
- 修复 SMB UNC 路径解析；丢弃大量保留条目时在后台清理，界面保持响应，期间切换选中行也会正确更新原任务的进度状态。

## 安装与升级

安装版在关闭程序后覆盖升级，保留密码库、设置和下载的引擎；ZIP 解压到新的空目录。安装 x64 或 ARM64 对应架构的 .NET 10 Windows Desktop Runtime（10.0.12 或更新的 10.0 补丁版）。如有保留中的解压任务，先完成或丢弃，再移动安装、切换架构或改变引擎。

跨重启续作保存完整条目与实际输出的校验记录，不保存密码，也不是单个大文件的字节偏移续传；固实包可能重新解码前缀。密码库主密码忘记后只能按事先导出的独立加密备份恢复，没有重置通道。

Windows 商业代码签名和第一层原生右键菜单不在本期发行范围；保留传统菜单。软件升级事务回滚尚未实现。真实多屏因设备受限未实测，不作为当前自用版本发行阻塞；讲述人实际发声验收为可选。
