# 密码分组、来源与重复整理

此功能包含在本地开发候选 0.2.0-preview.6，属于 B2 / F06。此段为早期实现背景，当前发行及开发状态以 CURRENT_STATE 为准。

在密码库添加或编辑记录时，可填写分组、来源和备注。分组用于列表筛选；来源是自己填写的标签，例如下载站点或文件分享者。搜索覆盖名称、备注、分组、来源和规则，不能按密码明文搜索。列表不显示密码；名称下显示整理信息，长文本可通过提示查看。

“优先尝试规则”默认折叠。填写“压缩包文件名包含”关键词，例如“照片”或“Trip”，会优先尝试此记录。按文件名做不区分大小写的子串匹配，不匹配父目录；来源标签不自动变为规则。不支持通配符或正则表达式，留空表示不设规则。

0.3.3新增“来源目录优先”：填写完整目录路径，匹配该目录及所有子目录（路径分段、不区分大小写），不读取目录内容。与文件名关键词任一匹配即可提升优先级，实际成功关联仍优先；来源标签继续仅作标签。目录规则可留空，支持本地盘符与 UNC 路径，不按简单前缀误匹配同名相邻目录。

自动尝试顺序如下：

1. 此压缩包实际成功关联的已启用记录。
2. 文件名符合关键词或来源目录规则匹配的已启用记录。
3. 最近成功时间较新的记录；没有成功记录时按较早创建时间排序。

相同密码仍只尝试一次。关键词不匹配的其它已启用密码不会被丢弃；停用自动尝试的记录不会因为关联或规则而被启用。只有实际解压成功后才更新成功记录，原有保存约定不变。

添加或编辑相同密码时会提醒，可取消并编辑已有记录，也可以确认保存。需要合并时，选择希望保留的记录，点击“合并重复”：

- 保留所选记录的名称、备注、分组、来源、关键词/来源目录规则及自动尝试设置；其它重复记录的这些字段被移除。
- 保留最早创建时间及最近成功时间。
- 把被移除记录的全部压缩包关联转到保留记录。
- 一次原子替换密码库，保留操作前的本机备份；取消或失败不修改原库。设置中的“恢复密码库备份”可以恢复最近一次写入前状态，不是多步撤销。

旧 APV1 库和 v1 加密便携备份没有新增字段时默认留空，读取不主动重写文件。新增元数据与密码一起受本机 DPAPI 或导出备份的 AES-GCM 加密保护；导入/导出保留这些字段。便携备份不迁移原电脑的路径关联。分组上限 128、来源 512、关键词 256、来源目录 1024 个 UTF-16 字符。没有目录字段的旧库/旧备份默认留空，不主动重写；新增目录值与其它元数据一起加密和备份。

验收只使用隔离目录和合成密码：旧格式库/备份、规则优先和候选保留、相同密码去重、合并关联、取消、失效记录、写入失败、恢复与便携备份共 30 项；实际编辑/筛选/搜索/重复确认/合并操作及普通/高对比度资源和 1120/800 宽度界面共 30 项。完整 Windows CI 结果记录在 [验收文档](ACCEPTANCE.md)。真实密码库与已安装软件不作为自动测试样本。
