nomozip 0.1.0-preview.4（Windows x64 开发预览）

安装版和独立 ZIP 版已携带 .NET 10 Windows Desktop Runtime，无需另行安装。
安装版：运行 setup-win-x64.exe，按向导为当前用户安装；从开始菜单打开 nomozip。
ZIP 版：解压到一个目录，运行 ArchivePassword.exe。
升级安装会保留本机密码库、设置与已下载的引擎。
卸载默认保留数据；只有明确勾选并确认后才删除本机数据。

1. 添加压缩包，或把文件拖入窗口。
2. 选择输出目录，点击“开始解压”。
3. 密码库有密码时自动尝试；没有可用密码时提示输入。
4. 勾选“成功后保存到密码库”，可供下次自动使用。
5. 在“密码库”中添加、编辑、搜索或删除密码。
6. 在“设置”中选择引擎并点击“使用所选版本”；可以恢复上一版本。
7. “导入更新包”支持本产品签名的 ZIP 包。校验后确认版本，再安装启用。
8. “压缩”页可添加文件/文件夹，选择 7z/ZIP、级别和保存位置后创建。新包校验成功后才保存或替换目标。
9. 勾选加密后输入或选择密码；成功后可保存到密码库。7z 支持中文密码和文件名加密；ZIP 的加密密码当前仅支持 ASCII。
10. “设置”可添加或移除 7z、ZIP、RAR 的打开方式入口；默认应用需在 Windows 设置中选择。

密码保存在当前 Windows 用户的本地目录中，并通过 Windows 用户加密保护。
跨电脑或重装系统时，不能假设直接复制密码库就可恢复。

当前开发预览的限制：
- 同一包多个不同密码的组合解压尚未完成。
- 软件下载与稳定引擎更新包分别发布：https://github.com/Nomoziya/nomozip/releases
- 设置中可检查、下载和验证产品渠道的引擎包。更新包由产品发布密钥签名。
- 已支持 7z/ZIP 创建与可选打开方式入口；不支持创建 RAR。
- 键盘、Narrator、高对比度和多屏 DPI 的完整人工验收尚待完成。

使用官方 7-Zip 引擎；许可证与来源信息见 licenses 文件夹。
